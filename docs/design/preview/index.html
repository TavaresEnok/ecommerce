Prancha de componentes e composições de tela

Referência visual original deste projeto para o redesign do painel, da vitrine e do checkout. Não é captura de outro produto. Lojas, pessoas, endereços, e-mails, pedidos e valores são fictícios; imagens de produto são ilustrações demonstrativas em SVG, não fotografias comerciais. Nenhum botão cria pedido, cobra, cancela ou salva dados.

Especificação: DESIGN.md e docs/design/. Tokens: docs/design/tokens.json. Verificação: node docs/design/verificar.mjs.
